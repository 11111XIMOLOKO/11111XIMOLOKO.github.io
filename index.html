Research Projects

Beyond Vibe Coding: A Controlled Experiment in AI-Assisted Development Completed

Vibe Coding — prompting AI in natural language to generate code — comes with a hidden cost: fast builds, expensive maintenance. I designed a controlled experiment: the same SDD spec (Specs → Design → Tasks), two implementations — one by AI alone, one with human-AI collaboration. The only variable: whether a human participated in iteration. Result: SDD solved the correctness problem, but experiential judgment still required human input. The methodology has since transferred to my diffusion model research. Tech stack: Vue 3 + Spring Boot + MyBatis-Plus + Redis.

Diffusion-based Industrial Defect Detection & Repair Pipeline Ongoing

A full-stack pipeline with five self-built modules: anomaly detection (WideResNet50 + K-means FAISS) → fake defect generation (fBm Perlin noise + Otsu masking) → ControlNet training (SD 1.5 Inpainting as base) → DDIM-Blending inference (pixel-exact background preservation) → evaluation (LPIPS + SSIM + MAE). ~2000 lines of self-written Python. Read BLDM source code to implement DDIM blending from scratch. Key engineering decision: fill defect regions with gray (in-distribution signal) rather than black (OOD input).
